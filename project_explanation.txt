# Portfolio Builder Project Explanation

## Introduction
This is a web application that allows users to create and manage their professional portfolios online. Think of it like a personal website builder specifically designed for portfolios. Users can showcase their projects, skills, and contact information using different design templates.

## Basic Concepts

### What is Django?
Django is a web framework for Python - think of it like a toolkit that helps you build websites. It follows a pattern called MVT (Model-View-Template):
- Models: Define your data structure (like a blueprint for your database)
- Views: Handle the logic (like a traffic controller for your website)
- Templates: Define how things look (like the HTML design of your pages)

### Project Structure

1. Main Components:
   - portfolio/: The main app folder containing all the code
   - templates/: Contains HTML files that define how pages look
   - static/: Contains files like images, CSS, and JavaScript
   - models.py: Defines the database structure
   - views.py: Contains the logic for handling web requests
   - urls.py: Defines the website's URLs (like a table of contents)

2. Key Features:
   - User Authentication (Login/Signup)
   - Portfolio Creation and Management
   - Project Management
   - Multiple Template Designs
   - Profile Management

## Detailed System Explanations

### Template Selection System
The template selection system is a core feature that works through several components:

1. Database Structure:
   - Templates are stored in the Template model
   - Each template has properties like name, preview image, and active status
   - Templates are linked to portfolios through a foreign key relationship

2. Selection Process:
   ```python
   # In views.py
   def template_selection(request):
       # Skip first three templates and show only active ones
       templates = Template.objects.filter(is_active=True)[3:]
       return render(request, 'portfolio/template_selection.html', {'templates': templates})
   ```

3. Template Application:
   - When a user selects a template, it's saved to their portfolio
   - The view_portfolio function uses a template mapping system:
   ```python
   template_map = {
       'Dark Mode': 'portfolio/templates/dark_mode.html',
       'Gradient': 'portfolio/templates/gradient.html',
       # ... other templates
   }
   ```
   - This mapping ensures the correct template file is used for rendering
