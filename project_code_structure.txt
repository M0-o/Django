3. Template Mapping System:
```python
# template_utils.py
TEMPLATE_MAP = {
    'Dark Mode': {
        'template_path': 'portfolio/templates/dark_mode.html',
        'css_class': 'dark-theme',
    },
    'Gradient': {
        'template_path': 'portfolio/templates/gradient.html',
        'css_class': 'gradient-theme',

def get_template_path(template_name):
    return TEMPLATE_MAP.get(template_name, {}).get(
        'template_path', 
        'portfolio/templates/default.html'
```

```python
@login_required
def edit_profile(request, portfolio_id):
    portfolio = get_object_or_404(Portfolio, id=portfolio_id, user=request.user)
    if request.method == 'POST':
        form = PortfolioEditForm(request.POST, request.FILES, instance=portfolio)
        if form.is_valid():
            form.save()
            messages.success(request, 'Portfolio updated successfully!')
            return redirect('view_portfolio', portfolio_slug=portfolio.slug)
    else:
        form = PortfolioEditForm(instance=portfolio)
    return render(request, 'portfolio/edit_profile.html', {'form': form})
```

### Integration System

1. Portfolio Display Controller:
```python
# views.py
def view_portfolio(request, portfolio_slug):
    portfolio = get_object_or_404(Portfolio, slug=portfolio_slug)
    template_name = get_template_path(portfolio.template.name)
    
    context = {
        'portfolio': portfolio,
        'projects': portfolio.project_set.all(),
        'skills': portfolio.skills.all(),
        'contact_info': portfolio.contact_info
    }
    
    return render(request, template_name, context)
```

```python
# project_utils.py
def format_project_for_template(project, template_name):
    """Formats project data according to template requirements"""
    formatted_data = {
        'title': project.title,
        'description': project.description,
        'image_url': project.image.url if project.image else None,
        'technologies': project.technologies.all(),
        'links': {
            'github': project.github_link,
            'live': project.live_link
        }
    }
    
    # Template-specific formatting
    if template_name == 'Dark Mode':
        formatted_data['description'] = mark_safe(
            highlight_syntax(project.description)
        )
    
    return formatted_data
```

## How Files Work Together

1. URL Request Flow:
   - User visits a URL
   - urls.py matches the URL pattern
   - Corresponding view function in views.py is called
   - View processes the request using models.py
   - Template is rendered with data
   - Response sent to user

2. Form Submission Flow:
   - User submits form
   - View receives POST request
   - Form is validated using forms.py
   - Data saved using models.py
   - Redirect or render response

3. Template Rendering Flow:
   - Base template provides structure
   - Specific template extends base
   - Dynamic content inserted
   - Static files (CSS/JS) included
   - Final HTML sent to browser

This structure follows Django's MVT pattern and separates concerns for better maintainability and scalability.
